# Maison — interactive design prototype

A static, illustrative personal-brand content workspace for Dubai real estate agents. Working name only.

This is a design review, not a live commercial service. AI editing, research, WhatsApp, publishing, and lead generation are not connected. Example profiles and imagery are fictional or illustrative.

Inputs are stored in the visitor’s own browser. Selected media is previewed locally, not uploaded. Do not enter real client or confidential information.

This repository contains only the standalone demo and hosting metadata—not private source documents, transcripts, customer data, or credentials.
