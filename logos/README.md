# App logos for the "Works with" strip

The landing page and the portal home show a rolling strip of the apps Maison works with. For each app below, add the brand's **official** logo as an SVG with exactly this file name. Until a file is added, the strip shows the app's name instead.

| File | App | Where to get the official logo |
| --- | --- | --- |
| `whatsapp.svg` | WhatsApp | Meta brand resources (WhatsApp) |
| `instagram.svg` | Instagram | Meta brand resources (Instagram) |
| `meta.svg` | Meta Ads | Meta brand resources |
| `tiktok.svg` | TikTok | TikTok brand guidelines / brand assets |
| `youtube.svg` | YouTube | YouTube brand resources |
| `linkedin.svg` | LinkedIn | LinkedIn brand guidelines (brand.linkedin.com) |
| `google-sheets.svg` | Google Sheets | Google Workspace brand / product icons |
| `notion.svg` | Notion | Notion media kit |
| `calendly.svg` | Calendly | Calendly brand assets |
| `property-finder.svg` | Property Finder | Ask their partnerships or marketing team |
| `bayut.svg` | Bayut | Ask their partnerships or marketing team |

Before launch, check each brand's rules for "works with" or integration logos (spacing, colours, no edits), and only list apps Maison actually connects to. Logos show in greyscale and turn to full colour on hover; the dark theme inverts them, so single-colour SVGs work best.
